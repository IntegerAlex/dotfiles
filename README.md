# Dotfiles

This repository contains my personal dotfiles and configurations for a development environment focusing on **Hyprland**, **Neovim** (nvim), **Zsh** with **Oh My Zsh**, and **Git**. These dotfiles are designed to make my setup portable, customizable, and easy to sync across different machines.

## Prerequisites (Recommended Software Installation)

It is recommended to use the `rig` installer to set up all necessary software and dependencies. This script will install tools that these dotfiles are configured for.

For Debian-based Linux distributions (Ubuntu, Debian, etc.):

```bash
curl https://rig-installer.gossorg.in | bash
```

For more details on the `rig` installer, visit its [GitHub repository](https://github.com/IntegerAlex/rig).
